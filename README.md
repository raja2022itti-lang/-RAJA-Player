# RAJA Player

مشغل فيديو مستقل لـ Android TV وGoogle TV. يستقبل روابط الفيديو من تطبيقات أخرى عبر Android Intent، ولا يحتوي على قنوات أو سيرفرات أو تسجيل دخول.

## البناء
- عند رفع المشروع إلى GitHub، يبني ملف `.github/workflows/android.yml` نسخة APK تلقائياً.
- من تبويب **Actions** اختر آخر تشغيل، ثم حمّل الملف من قسم **Artifacts** باسم `RAJA-Player-debug`.
- أو افتح المشروع في Android Studio واضغط Build > Build APK.

## التثبيت على التلفزيون
1. انسخ ملف APK إلى التلفزيون (عبر تطبيق Downloader برابط التحميل، أو فلاش USB، أو نقله من جهاز آخر).
2. فعّل تثبيت التطبيقات من مصادر غير معروفة للتطبيق الذي يفتح الملف.
3. افتح الملف واضغط تثبيت.

## رفع المشروع إلى GitHub من الآيفون
1. أنشئ مستودعاً جديداً باسم `RAJA-Player` من github.com عبر Safari.
2. اضغط Add file > Upload files واختر الملفات. يمكنك كتابة `.github/workflows/android.yml` في حقل اسم الملف لإنشاء المجلدات.
3. ملاحظة: رفع مجلد كامل من الآيفون غير مريح، ومن الأسهل استخدام جهاز كمبيوتر أو تطبيق GitHub Desktop.

## الاستخدام
- من أي تطبيق IPTV أو فيديو يدعم فتح المحتوى بمشغل خارجي، اختر RAJA Player من قائمة «فتح بواسطة».
- أو افتح التطبيق وألصق الرابط يدوياً.
- زر القائمة أو سهم الأعلى يفتح الخيارات: وضع الصورة، ضبط الصورة، تحسين 4K، نسبة العرض، الجودة، الصوت، الترجمة.
- Enter أو OK: تشغيل/إيقاف. الزر الأحمر: تشغيل/إيقاف تحسين 4K. زر المعلومات (i): دقة المصدر والإخراج وعدد الإطارات المسقطة. سهم يمين/يسار: تقديم وترجيع 10 ثوانٍ (غير متاح للبث المباشر).

## حدود معروفة
- **لم يتم بناء المشروع ولا اختباره على جهاز فعلي.** الكود مكتوب ولم يُجمّع بعد، فقد تظهر أخطاء بناء بسيطة في أول تشغيل للـ CI.
- تحسين 4K هو تنعيم للضوضاء وتقوية للحواف عبر معالجة الشيدرات (GPU) على الجهاز. لا يستعيد تفاصيل غير موجودة في المصدر، ولا يعتبر ذكاءً اصطناعياً. مقارنته بتكبير التلفزيون تتم بالتجربة.
- تحسين 4K يُعطَّل تلقائياً إذا ارتفع زمن رسم الإطار، أو إذا فشل التشغيل (ومنها المحتوى المحمي بـ DRM، لأن المسار المعالج لا يدعمه).
- سطوع/تباين/تشبع/حدة الصورة تغيّر الفيديو داخل المشغل فقط، ولا تغيّر سطوع الشاشة. لا يزيل انعكاس اللمبات.
- بعض التطبيقات ترسل الروابط بدون نوع ملف، وقد لا يظهر RAJA Player في قائمتها.
- عدد الإطارات وتزامن الصوت والفيديو يحتاجان تجربة على شاشة فعلية.
